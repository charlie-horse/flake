# c4130: GPU inference host

c4130 is the server with the GPUs; it runs vLLM. Config: `hosts/c4130/`
(vLLM and LMCache: [c4130-vllm.md](c4130-vllm.md)).

## Deploying c4130

Every change, a model entry or a `vllm-fork` re-lock included, goes through
this repo: branch, CI, merge. Then, as admin on c4130
([access](../../CLAUDE.md#access)):

```sh
# 1. GC first, every time
sudo nix-env -p /nix/var/nix/profiles/system --delete-generations +2 && sudo nix-collect-garbage
df -h /
# 2. pull and build (no sudo; the build runs on the remote builder)
cd /etc/nixos && git pull && nixos-rebuild build --flake /etc/nixos#c4130
# 3. optional, around risky starts: the RAM guard (see below)
# 4. switch
sudo nixos-rebuild switch --flake /etc/nixos#c4130
```

Then finish as in [Changing a host](../cluster.md#changing-a-host): one host
at a time, `systemctl --failed`, the etcd health check.

- **GC before every switch.** GC (garbage collection) deletes old system
  generations and the store paths nothing uses. After a switch that
  replaces the Flint checkpoint, GC again to drop the old checkpoint.
- What c4130 runs: `nix-store -qd /run/current-system` and
  `git -C /etc/nixos log -1`. The deployed `vllm-fork` commit is the one in
  `flake.lock` at that commit; `main` may be ahead.
- **RAM guard.** `~admin/archive/notes/flint-nix/ramguard.sh` stops vllm and
  LMCache if MemAvailable drops under 6 GB, and exits after about 25
  minutes. Run it with
  `sudo systemd-run --unit=ramguard --collect ~admin/archive/notes/flint-nix/ramguard.sh`
  around risky starts: a new model, a bigger L1, a `vllm-fork` bump.
- **Remote builder down** ([build-cache.md](../build-cache.md)): build on
  c4130 with `--option max-jobs 4`, and stop LMCache first, or the build
  runs out of RAM.

## Operational gotchas

- **`nixos-rebuild build` writes `./result`.** To only check that it
  builds, use `nix build --no-link` so `~/result` stays as it is.
- md RAID events go to the journal (there is no mail server):
  `journalctl -t mdadm`.
